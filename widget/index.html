ウィジェット

アプリを開かなくても、友達の「いま」がホーム画面に届きます。ぽつりには2種類のウィジェットがあります。

みおいつメン ・ 3 min

ぽつり

グループの友達が置いた、いちばん新しい近況を表示します。スマホを見たとき、そこに友達がいる。

今日の気分

アプリを開かずに、タップするだけで気分スタンプをグループに置けます。ひとことも考えなくていい、いちばん軽い近況です。

ホーム画面に追加する方法

  1. ホーム画面を長押しアイコンのない場所を、アイコンがふるえるまで長押しします。
  2. 「編集」→「ウィジェットを追加」左上の「編集」をタップして、「ウィジェットを追加」をえらびます。
  3. 「ぽつり」をさがす検索欄に「ぽつり」と入れて、アプリをえらびます。
  4. 種類とサイズをえらぶ左右にスワイプして「ぽつり」か「今日の気分」、小か中のサイズをえらび、「ウィジェットを追加」をタップします。
  5. 好きな場所に置く置きたい場所まで動かして、右上の「完了」をタップすれば完成です。

iPhoneのバージョンによって、ボタンの名前が少しちがうことがあります。

📝

知っておきたいこと

  • 友達が置いてから、ウィジェットの表示が変わるまで数分かかることがあります。これはiPhoneがウィジェットを更新するタイミングによるものです。
  • ウィジェットに出るのは、あなたが入っているグループの近況だけです。
  • 近況は24時間で消えるので、ウィジェットからも消えます。
  • 「今日の気分」で置いたスタンプも、ふつうの近況と同じようにグループの友達に届きます。
